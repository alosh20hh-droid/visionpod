# VisionPod — اختبار كاميرا الهاتف مع نموذج رؤية

هذا نموذج أولي للتجربة فقط:
- صفحة ويب تفتح كاميرا الهاتف عبر HTTPS.
- تلتقط صورة عند ضغط المستخدم، ولا ترسلها تلقائيًا.
- ترسل الصورة والسؤال إلى FastAPI داخل بيئة Linux.
- يرسل الخادم الصورة إلى Gemini API ويعيد الإجابة.
- لا يخزن التطبيق الصور عمدًا.

## تنبيه الخصوصية والتكلفة
- لا تصوّر أشخاصًا أو وثائق أو معلومات حساسة.
- عند الضغط على «إرسال الصورة وتحليلها»، تُرسل الصورة إلى خادمك ثم إلى Google Gemini API.
- استخدام Gemini API يخضع لتوفر الخطة المجانية وحدودها وسياسات Google؛ لا تفترض أن الاستخدام غير محدود.
- في الخطة المجانية، قد تُستخدم البيانات لتحسين المنتجات بحسب شروط Google. راجع الشروط الحالية قبل استخدام صور خاصة.
- لا تضع مفتاح API في كود الواجهة أو في GitHub. خزّنه كمتغير بيئة/Secret على الخادم.
- هذا نموذج تجريبي وليس خدمة آمنة للإنتاج أو للاستخدام الطبي/الكهربائي/الميكانيكي عالي الخطورة.

## تشغيله محليًا أو في بيئة Linux
1. ثبّت Python 3.11 أو أحدث.
2. ثبّت المتطلبات:
   `pip install -r requirements.txt`
3. أضف مفتاح Gemini إلى متغير البيئة `GEMINI_API_KEY`.
4. شغّل:
   `uvicorn app:app --host 0.0.0.0 --port 8000`
5. افتح المنفذ 8000 عبر HTTPS إذا ستدخل من هاتفك؛ المتصفح يحتاج سياقًا آمنًا لتشغيل الكاميرا.

## تشغيله داخل Docker
`docker build -t visionpod-test .`
`docker run --rm -p 8000:8000 -e GEMINI_API_KEY=YOUR_KEY visionpod-test`

استبدل YOUR_KEY بالمفتاح في الطرفية فقط. لا تشارك سجل الطرفية أو المفتاح.

## فحص سريع
- افتح `/health` ويُفترض أن يظهر `{"ok":true,...}`.
- افتح الصفحة الرئيسية من هاتفك عبر HTTPS.
- اضغط تشغيل الكاميرا، ثم التقاط صورة، ثم إرسال الصورة وتحليلها.

إذا لم تضف `GEMINI_API_KEY`، يعمل التطبيق بوضع الاختبار: يستقبل الصورة داخل حاوية Linux ويعرض أبعادها وحجمها، دون تحليلها. أضف المفتاح فقط عندما تريد تفعيل نموذج الرؤية.
